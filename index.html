Backup & Restore

All data lives only in this browser. Export a backup regularly, especially before clearing browser data or switching devices.

Excel import matches rows to existing students by Student ID and updates them, or adds new students/payments/expenses when the ID is blank or not found. PDF is export-only — PDF files don't hold structured data, so they can't be imported back; use the JSON or Excel backup for that. Excel and PDF export need an internet connection the first time (to load the export library); JSON backup always works offline.
